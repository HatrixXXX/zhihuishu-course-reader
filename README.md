# 智慧树课程助手

适用于自动化学院《国家安全概论》研究生课程，课程 ID 为 `2101609010059079680`，班级 ID 为 `299118`。

[打开课程目录](https://ai-smart-course-student-pro.zhihuishu.com/singleCourse/knowledgeStudy/2101609010059079680/299118)

这是针对上面这门课程编写的浏览器脚本，运行范围固定为该课程和班级。

## 下载

- [便携安装包 ZIP](https://github.com/HatrixXXX/zhihuishu-course-reader/releases/latest/download/zhihuishu-course-reader-v1.0.4.zip)：解压后打开 `安装助手.html`，按提示复制和安装。适合换电脑使用。
- [直接安装用户脚本](https://github.com/HatrixXXX/zhihuishu-course-reader/releases/latest/download/course-reader.user.js)：浏览器已安装篡改猴或脚本猫时，可通过管理器安装。
- [版本与下载列表](https://github.com/HatrixXXX/zhihuishu-course-reader/releases)。

## 安装和使用

1. 在你已有的篡改猴或脚本猫中**新建脚本**。
2. 打开 `dist/国家安全概论-全部资源.user.js`，复制全部内容，替换新建脚本的默认内容并保存。无需安装 Node.js。
3. 刷新课程目录，右下角应出现“全资源学习助手”。点击“开始/继续”。

新电脑需要安装脚本管理器并登录课程账号，无需安装 Node.js、Python 或启动本地服务。本工具的本地断点不会随安装包迁移；新电脑会重新扫描课程，平台已完成的视频仍会跳过。

初次运行会扫描目录。必学和选学都会处理，目录中已经显示 100% 的知识点也会进入检查。

- PPT、PDF、文档和图文：点击资源卡片，等待页面切换和加载，停留 3 秒后继续。PPT 不逐页翻看。
- 外链：点击平台的资源卡片，使用脚本管理器在后台打开目标页面，停留 3 秒后关闭该标签页。无类型标记的卡片只有在点击时取得有效 HTTP/HTTPS 外链后才会记为已打开。目标网站的内容加载、验证和阅读情况无法跨域验证。
- 视频：默认静音、1 倍速，等待播放器真实结束。平台卡片已经明确显示完成的视频会跳过，不重复播放。
- 知网安全验证链接：已确认的卡片标题、卡片直链，或点击时请求打开的知网地址会留待人工处理，继续遍历后面的资源；不会将其记为已打开。全部遍历后，右下角报告列出跳过项、课程位置链接，以及能取得的知网直链。

“暂停”会停止调度并暂停当前视频。再次点击“开始/继续”会保留断点。工具切换知识点后会继续运行；刷新同一标签页也会尝试恢复。浏览器关闭后，重新打开课程目录并点击“开始/继续”即可。

“清除本地断点”只清除本工具的记录。清除后文档和链接会重新打开，平台已经完成的视频仍会跳过。

## 自动继续和异常

单项资源遇到登录、验证、答题弹窗，视频加载失败或长时间不前进，文档预览失败、外链无法打开，或资源类型仍无法识别时，会记录原因并继续后续资源；资源列表始终无法加载时，会将整个知识点列入待人工处理。最终报告提供待处理项目和课程位置链接。跳过的视频不会记为已播放结束，跳过的文档和链接不会记为已打开。

手动点击“暂停”、离开指定课程、手动切换知识点，或另一个标签页接管时，运行仍会停止，以免写入错误断点。平台弹窗可能导致后续多项资源连续列入待人工清单，脚本不会绕过验证或代答。

如果课程目录本身无法加载知识点清单，工具无法确定后续章节，仍需先登录或刷新页面。浏览器休眠或完全挂起标签页时，脚本也无法继续执行。

如果提示另一个标签页正在运行，请回到那个标签页暂停。那个页面已经关闭时，等待约 15 秒后再开始。

播放期间保留课程页面，避免手动切换知识点或资源。浏览器在最小化、后台节流或电脑休眠时可能暂停播放；工具不会绕过浏览器或平台的限制。右侧 AI 学伴不会自动作答，作业、考试和掌握度测验需要自行处理。

## 已验证的范围

开发时读取了真实课程的两个模块、25 个知识点，以及一个知识点内的 PPT、视频和知乎外链卡片结构。本地测试覆盖完整安装包启动、全部资源遍历、重名资源、暂停恢复、播放器复用、旧媒体残留和多标签页互斥。

浏览器控制连接不稳定，尚未在真实平台上完整跑过这门课程。日志中的“已打开”或“视频已播放结束”表示工具观察到的操作结果；学习进度和计分以平台页面为准。

## 开发

Node.js 24.15.0 下执行：

```powershell
npm install --ignore-scripts
npm test
npm run check
npm run build
```

生成包含脚本、离线安装页和安装说明的便携 ZIP，需要另外安装 Python 3：

```powershell
npm run package
```

源码位于 `src/`，测试位于 `tests/`。`scripts/build.js` 生成单文件用户脚本，`scripts/package_release.py` 生成便携安装包并检查归档完整性及安装页中的脚本内容。

运行时没有外部依赖，也不会读取账号密码、调用学习进度接口或提交答题。断点保存于脚本管理器。项目缓存位于 `.codex-cache/`；可安装文件在 `dist/`。
